# API service

FastAPI service that serves the decentralization report as JSON for explorers to embed.
Read-only, CORS-open, versioned under `/v1`.

## Run

```
pip install -r requirements.txt
uvicorn api.server:app --reload --port 8000
```

Interactive docs at `http://localhost:8000/docs`.

## Endpoints

| Endpoint | Returns |
|---|---|
| `GET /v1/report/latest` | full report for the latest epoch |
| `GET /v1/report/{epoch}` | full report for a specific epoch |
| `GET /v1/clusters/{epoch}` | just the operator clusters for an epoch |
| `GET /v1/metrics/timeseries` | concentration indices across epochs (feeds charts) |
| `GET /v1/report/{epoch}/snapshot.json` | frozen, archivable snapshot |
| `GET /v1/dashboard-data` | one bundle for the SPA (report + timeseries + per-epoch bubbles) |

## Live vs. sample

If the pipeline can reach `rpc.qubic.org`, the service builds fresh data. Otherwise it
falls back to the static snapshots in `api/sample/` (generated by
`scripts/generate_sample.py`), so the API and dashboard always have something to render.
Sample responses are flagged (`"sample": true` where applicable, and reports carry
`"_sample": true`).

> Note: some hosted/build environments block outbound access to `rpc.qubic.org`. Run the
> live pipeline where that host is reachable; point `QUBIC_RPC_BASE` at a mirror if needed.
